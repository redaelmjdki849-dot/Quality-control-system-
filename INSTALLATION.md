# Installation Guide | دليل التثبيت | Guide d'Installation

## المتطلبات | Prérequis | Requirements:
- Node.js v16+
- Python 3.8+
- MongoDB or SQLite
- Git

## الخطوات | Étapes | Steps:

### 1. استنساخ المستودع | Cloner le dépôt | Clone Repository:
```bash
git clone https://github.com/redaelmjdki849-dot/Quality-control-system-.git
cd Quality-control-system-
```

### 2. تثبيت الاعتماديات | Installer les dépendances | Install Dependencies:
```bash
npm install
```

### 3. تشغيل التطبيق | Exécuter l'application | Run Application:
```bash
npm start
```
