## 📋 الميزات | Caractéristiques | Features

### البيانات المدارة | Données Gérées | Managed Data:
- ✅ Nom Fournisseur (اسم المورد) - Supplier Name
- ✅ Part Number (رقم القطعة) - Part Number
- ✅ Number Carton (رقم الكرتون) - Carton Number
- ✅ Batch Number (رقم الدفعة) - Batch Number
- ✅ Site (الموقع/الفرع) - Site/Location
- ✅ PCS OK (القطع السليمة) - Good Pieces
- ✅ PCS NOK (القطع المعيبة) - Defective Pieces
- ✅ PCS Total (إجمالي القطع) - Total Pieces
- ✅ Total Stock (إجمالي المخزون) - Total Stock

### الرسوم البيانية | Graphiques | Charts:
- 📊 نسبة القطع السليمة والمعيبة
- 📈 الإحصائيات الشهرية
- 🗺️ توزيع المخزون حسب الموقع
- 📉 تقارير الأداء

### المنصات | Plateformes | Platforms:
- 💻 تطبيق ويب (Web Application)
- 🖥️ تطبيق سطح المكتب (Desktop Application)

### اللغات | Langues | Languages:
- 🇸🇦 العربية
- 🇫🇷 الفرنسية
- 🇬🇧 الإنجليزية
